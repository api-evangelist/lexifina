Lexifina provides a Legal AI drafting and automation platform that aggregates global law data, offering tools for drafting, reviewing, and redlining legal documents. The service includes a searchable global law database, AI-powered insights, integrations with Microsoft Word, Outlook, and Chrome, and a suite of resources such as blogs, pricing details, and security information. It aims to streamline legal workflows for firms and professionals by delivering up-to-date legislative changes and AI assistance across the legal lifecycle.

**Areas:** Legal AI · Document Automation · Contract Drafting · Collaboration Tools · Enterprise Security · API

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Lexifina: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
